# GitHub Setup Instructions

## Prerequisites

1. **Install Git** (if not already installed):
   - Download from: https://git-scm.com/download/win
   - Or use: `winget install Git.Git` (if winget is available)

2. **Install GitHub CLI** (optional, but recommended):
   - Download from: https://cli.github.com/
   - Or use: `winget install GitHub.cli`

## Steps to Push to GitHub

### Option 1: Using Git Commands (Recommended)

1. **Open PowerShell or Command Prompt** in the project directory:
   ```powershell
   cd C:\Users\musaw\Desktop\medical-agentic-system
   ```

2. **Initialize Git repository** (if not already initialized):
   ```bash
   git init
   ```

3. **Add the remote repository**:
   ```bash
   git remote add origin https://github.com/haniazahra9706/lab-report-analyzer.git
   ```

4. **Add all files**:
   ```bash
   git add .
   ```

5. **Commit the changes**:
   ```bash
   git commit -m "Initial commit: Medical Lab Report Analyzer with multilingual support and voice features"
   ```

6. **Push to GitHub**:
   ```bash
   git branch -M main
   git push -u origin main
   ```

   **Note**: You may be prompted for GitHub credentials. Use a Personal Access Token (PAT) instead of password:
   - Create PAT: https://github.com/settings/tokens
   - Select scopes: `repo` (full control of private repositories)

### Option 2: Using GitHub Desktop

1. Download GitHub Desktop: https://desktop.github.com/
2. Sign in with your GitHub account
3. File → Add Local Repository → Select this folder
4. Publish repository → Choose the remote: `haniazahra9706/lab-report-analyzer`

### Option 3: Using VS Code

1. Open the project in VS Code
2. Install the "Git" extension (if not already installed)
3. Open Source Control panel (Ctrl+Shift+G)
4. Click "Initialize Repository"
5. Stage all changes
6. Commit with message
7. Click "Publish Branch" and select the remote repository

## Important Notes

- **`.env` file is excluded** from git (contains API keys) - make sure it's in `.gitignore`
- **`medical_kb.json` is included** - this is the knowledge base file
- **PDF sample files** are included - remove from `.gitignore` if you want to exclude them
- **Audio files** generated by voice features are excluded
